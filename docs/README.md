# Project notes

This folder keeps the working notes that are useful during development but do not need to stay in the public entry points of the repository.

- `PROGRESS.txt` — running development log and current focus
- `ROADMAP.md` — planned work and future scope
- `QA_AUDIT.md` — risks, findings, and validation notes
- `GAME_FLOW_MAP.md` — runtime behavior and system flow
